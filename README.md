## ⚠️ Disclaimers

* **Not Official NTA:** This application is **not** operated by, endorsed by, sponsored by, or affiliated with the **National Testing Agency (NTA)** or the Government of India in any way.
* **Fan-Made Concept Only:** Built as an independent UI/UX and local CBT practice concept for self-study and demonstration purposes.
* **Selected Practice Set (Not a Full Official Paper):** The built-in question set contains **30 selected previous-year questions (PYQs)** (10 each from Physics, Chemistry, and Mathematics, transcribed/paraphrased from the *JEE Main 2026 · 02 April · Shift 1* paper, with a maximum practice score of **120 marks**). A complete official JEE Main Paper 1 contains **75 questions** and **300 marks**.
* **No Official Scores or Ranks:** Any score, accuracy metric, or summary shown in this app is calculated locally from the embedded study key for practice only. It is **not** an official NTA score, NTA percentile, All India Rank (AIR), or admission credential.
* **Study Reference Note:** Question stems and worked explanations are provided as study aids; always verify official papers, keys, and rules against official NTA publications.

---

## Features

* **CBT Exam Flow:** Candidate entry screen, multi-page instructions (with English and Hindi UI text support on the instructions screen), timed exam workspace, submission confirmation modal, scorecard, and solution review.
* **Subject & Question Navigation:** Switch across **Physics**, **Chemistry**, and **Mathematics** tabs, jump directly via the **Question Palette**, or use keyboard shortcuts (`Alt + Left/Right` to move between questions, `Esc` to close the submit modal).
* **Answer States & Palette Tracking:** Tracks *Not Visited*, *Not Answered*, *Answered*, *Marked for Review*, and *Answered & Marked for Review*, along with *Save & Next*, *Mark for Review*, *Review & Next*, and *Clear Response*.
* **MCQ & On-Screen Numeric Keypad:** Supports single-choice MCQs and integer numerical responses via a clickable keypad (including negative sign, backspace, and clear).
* **Scoring & Review Mode:** Applies **+4** for correct responses, **−1** for incorrect responses, and **0** for unattempted questions, followed by a subject-wise breakdown and worked explanations.
* **Single-File Local Session:** Runs directly in the browser from a single HTML file with no backend required; session progress stays in the active browser tab.

## How to Run Locally

1. Download or clone the repository.
2. Open the HTML file (e.g., `jee-main-cbt-simulator.html`) directly in any modern web browser (Chrome, Edge, Firefox, Safari).
