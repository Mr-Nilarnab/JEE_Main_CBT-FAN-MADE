General Instructions

Read the information below carefully before starting the test.

  1. This practice set contains 30 selected JEE Main previous-year questions: 10 each in Physics, Chemistry and Mathematics.
  2. Each subject contains 8 single-correct MCQs and 2 numerical-value questions in this selected set.
  3. This is one continuous Paper 1 (B.E./B.Tech) practice session with a 180-minute (3-hour) countdown. This build contains 30 selected PYQs (10 per subject), so its practice-set maximum is 120 marks; the complete NTA Paper 1 has 75 questions and 300 marks.
  4. Marking: +4 for a correct response, −1 for an incorrect response and 0 for an unanswered question.
  5. Use the question palette to jump between questions. Your selected answers are retained when you move between questions.
  6. Use Save & Next to move forward, Mark for Review to flag a question, and Clear Response to remove a selected answer.
  7. The test submits automatically when the timer reaches zero. You can submit manually at any time.

JEE Main CBT Practice is an independent, offline-first computer-based test simulator developed by Mr-Nilarnab. It is not affiliated with, endorsed by, or operated by the National Testing Agency (NTA).

The built-in set is a selected 30-question practice set transcribed/paraphrased from the JEE Main 2026, 2 April, Shift 1 paper. It is not the complete 75-question official paper.
